# Projeto Rover

Este projeto apresenta um sistema simples de inicialização de um Rover, desenvolvido em JavaScript. Ao executar o programa, são exibidas informações sobre o funcionamento dos sistemas do Rover, incluindo o status dos painéis solares e o nível da bateria.
